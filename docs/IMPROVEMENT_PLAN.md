# 星屿手记 · 完善改进方案（基于 6 个同类博客调研）

> 2026-09-06 · 调研对象：moejue.cn、zmoe.com（=blog.kt.sb）、hackyh.com、himiku.com、onetuzi.cn（=023.me）、bimoes.com，外加 moejue.cn/links 友链页专项分析。
> 结论先行：星屿手记在「社区系统、保险库、音乐播放器、视觉氛围」上已领先同类站，真正的差距集中在三处——**数据闭环（阅读量/统计/热门）**、**内容形态（说说/追番/相册）**、**友链生态（规则/朋友圈/读者墙）**。

## 一、逐站对比

### 1. moejue.cn（阿珏酱のBlog）— WordPress + 自研 LoLiMeow 主题
- **有而我没有**：文章卡片显示阅读量与评论数；首页侧栏「最新评论」「标签云」「随机推荐旧文」「GitHub 足迹」；读者墙、追番页、相册页、真实打赏（投喂外链到商品页）；评论颜文字表情；中/英/日/繁多语言；页脚 10+ 社交链接矩阵（QQ群/微博/B站/X/Steam/网易云…）。
- **我更强**：视觉氛围（封面带/波浪/玻璃卡）、音乐播放器、社区账号体系（它只有基础登录）、零知识保险库。
- **值得抄**：阅读量+评论数上卡片；最新评论侧栏；投喂做成真入口。

### 2. moejue.cn/links（友链页专项）
- 分组展示（个人项目 / 主要友链 / 小伙伴 / 其他）；明确列出**本站信息**（名称/描述/头像 URL）供对方复制；**申请规则**写得很具体：先加友链、长期更新、原创 30+ 篇、建站一年以上、非免费域名，「二次元的小伙伴无视以上要求」（豁免条款很有梗）；申请通过**评论区**提交并沉淀为 298 条互动记录。
- **值得抄**：分组 + 本站信息卡 + 申请规则三件套；豁免条款式的人格化文案。

### 3. zmoe.com = blog.kt.sb（A/B's Blog，B分之A）— WordPress + iEmo 魔改，12 年老站
- **有而我没有**：**说说页**（微博式短内容，庆祝第 300 篇文章）；首页「最新发布 / 为你推荐」双标签切换；随机友链区块；每篇浏览量；嵌套评论 @回复。
- **教训**：服务器到期丢过数据库，靠备份 + AI 辅助重构复活 → **D1 定时备份必须做**。
- **值得抄**：说说（与本项目一言/看板娘气质高度契合）；双标签文章流。

### 4. hackyh.com（Hackyh'Blog）— Z-BlogPHP
- **有而我没有**：页脚「本站已安全运行 3700 天」计时器；站点统计（文章/评论/浏览量/标签计数）；多彩标签云；QQ 一键登录；**在线工具箱/导航站**子站；访客 IP 分布挂件。
- **值得抄**：运行天数计时器（成本最低、氛围感最强的一项）；标签云带计数。
- **不建议抄**：信息密集双栏布局与本项目沉浸式视觉路线冲突；VIP 解析类功能有合规风险。

### 5. himiku.com（初之音）— Typecho + VOID（博主是主题/插件作者）
- **有而我没有**：文章卡片与文章页的**字数统计**（+393 字）；**追番页**（Bangumi 收藏展示）；**照片页**；留言 chat 页；Anubis PoW 反爬盾。
- **特别启发**：博主通过自研插件（PandaBangumi、FeedEnhancer、DarkMode）让博客成为**作品集入口**——星屿手记的保险库、播放器、社区系统完全可以同样「作品化」包装，写配套技术文章。
- **值得抄**：字数统计（纯前端可算）；追番页（Bangumi API 公开免费）。

### 6. onetuzi.cn = 023.me（彼岸临窗，律师博客）— Halo 2.x
- **有而我没有**：**「瞬间」页**（Halo 瞬间插件，微博式动态）；极简文学风排版；ICP + 公安双备案的规范页脚。
- **值得抄**：瞬间（与说说同构，二选一即可）；备案/版权页脚规范（公开部署前联动 TECH_DEBT）。
- 备注：该站多次更换域名（023.me 为新域），提示**域名/数据可迁移性**要提前设计。

### 7. bimoes.com（彼萌）— Typecho
- **有而我没有**：**Ctrl+K 快捷搜索**；侧栏「博客信息」卡（文章数 / **运行天数 6年233天** / 最后活动时间）；热门文章双 tab（点赞/打赏榜）；标签云。
- **值得抄**：Ctrl+K（搜索弹窗已有，只差快捷键）；统计信息卡。

### 8. 生态补充（联网搜索）
- 友链朋友圈方案：[友链朋友圈官方文档](https://fcircle-doc.yyyzyyyz.cn/)（RSS 聚合 + AI 摘要）、[Friend-Circle-Lite](https://github.com/Hsuant/Friend-Circle-Lite)（无数据库 JSON 轻量版）、[安知鱼主题更新日志](https://hexo.anheyu.com/update/)（说说/朋友圈/随机友链已成现代主题标配）。
- 星屿手记用 **CF Workers Cron Triggers + D1** 自建聚合即可，不依赖第三方服务，贴合现有零外部依赖架构。

## 二、星屿手记现状盘点（对比基线）

**已领先同类站**：零知识加密保险库（独一份）、社区系统一期（注册/登录/评论/留言/友链提交 + studio 审核台）、网易云音乐播放器（队列/歌词/今日推荐）、全站搜索弹窗、文章页 TOC + 上一篇/下一篇 + 相关文章 + 阅读进度条、看板娘/樱花/一言/波浪分隔、QQ 风格名片、RSS + sitemap、AVIF/WebP 壁纸优化。

**确认不缺**（调研前担心、实际已有）：文章目录、上下篇导航、相关文章、图片灯箱。

**核心短板**：① 除文章数外没有任何真实运行数据（无阅读量、无运行天数、无总评论数）；② 内容只有「文章」一种形态，缺说说/追番/相册这类轻内容；③ 友链页只有提交表单，无规则、无分组、无生态玩法；④ 头像/昵称/评论数据已沉淀在 D1 却没有回流到前台（无最新评论、无读者墙）。

## 三、改进方案（按优先级）

### P0 · 数据闭环 —— 让博客「活着」（预计 1~2 天）
| # | 改进 | 参照 | 实现要点 |
|---|---|---|---|
| 1 | 文章阅读量 + 点赞 | moejue / zmoe / bimoes | D1 新表 `article_stats(slug, views, likes)`，API 计数；文章页与首页卡片展示 |
| 2 | 字数统计 | himiku | `content.ts` 渲染时统计正文字符数，卡片显示 `+N 字` |
| 3 | 页脚站点统计 | hackyh / bimoes | 运行天数（以首个提交日期起算）+ 文章/评论总数，接进现有页脚或名片卡 |
| 4 | 代码块复制按钮 + 复制加版权 | 通用标配 | `renderMarkdown` 输出后挂客户端增强组件 |
| 5 | Ctrl/Cmd+K 唤起搜索 | bimoes | 搜索弹窗已存在，全局 keydown 一行逻辑 |

### P1 · 社区氛围 —— 存量数据回流（预计 2~3 天）
| # | 改进 | 参照 | 实现要点 |
|---|---|---|---|
| 6 | 友链页 2.0：分组 + 本站信息卡 + 申请规则 + 随机跳转 | moejue/links | 纯前端改造 + 规则文案；「二次元豁免」式人格化条款 |
| 7 | 最新评论区块（首页/留言板） + 读者墙 | moejue / zmoe | D1 已有 `article_comments`（含昵称/头像），一条聚合查询 |
| 8 | 评论表情（颜文字起步） | moejue OωO | 表情选择器 + 存储转义，挂进现有评论组件 |
| 9 | 说说/瞬间页 | zmoe 说说 / onetuzi 瞬间 | D1 一张 `moments` 表 + studio 发布入口 + 时间流页面；仅站主可写 |

### P2 · 特色内容页 —— 二次元博客的「人格」（预计各 0.5~1 天）
| # | 改进 | 参照 | 实现要点 |
|---|---|---|---|
| 10 | 追番页（Bangumi 收藏） | himiku / moejue | Bangumi 公开 API + 收藏数据静态化或 D1 缓存 |
| 11 | 相册页 | moejue / himiku | 静态图片数据起步，复用 image-preview 灯箱 |
| 12 | 收藏/工具页 | bimoes「收集」 / hackyh 工具箱 | 静态链接卡片集，可作为友链的补充 |

### P3 · 进阶玩法与运维（择机）
| # | 改进 | 参照 | 实现要点 |
|---|---|---|---|
| 13 | 友链朋友圈 | fcircle / Friend-Circle-Lite | CF Workers Cron 定时抓友链 RSS → D1 → /friends-circle 页；可选 Workers AI 摘要 |
| 14 | 文章 AI 摘要卡 | fcircle AI / 安知鱼 | Workers AI 生成一次、缓存进 D1，失败静默降级 |
| 15 | D1 定时备份 | zmoe 丢库教训 | wrangler d1 export 定时任务或手动脚本入 Git LMS/对象存储 |
| 16 | OG 图自动生成、PWA、多语言 | moejue 多语言 | 远期，性价比低于上列各项 |
| 17 | 公开部署必办 | TECH_DEBT.md | 替换 wrangler.jsonc D1 database_id、壁纸授权确认、（如需）ICP 备案 |

## 四、建议落地顺序

1. **第一批（数据闭环）**：P0 全部 —— 改完首页卡片与页脚立刻「有数据味」。
2. **第二批（氛围）**：友链页 2.0 + 最新评论 + 读者墙 —— 社区系统投入已有回报的第一步。
3. **第三批（人格）**：说说页 → 追番页。
4. **第四批（生态）**：友链朋友圈（等友链数量 > 5 再做，否则页面空）。
5. 随动：每次新增页面同步 sitemap / 导航入口 / 进度文档。

—— 本方案由 2026-09-06 的同类站调研生成，调研快照见对话记录；各站功能可能迭代，实施前可复查。
