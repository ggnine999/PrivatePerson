# 技术债与上线前检查清单

更新时间：2026-09-07
维护约定：解决一项就移入「已解决」；新增债务按优先级追加并标注位置与建议。

## 高优先（公开部署前必办）

- [ ] **壁纸/贴纸素材授权确认**：`public/images/saber-meadow-v2.avif`、`.webp` 源自 Wallpaper Engine 预览扩展生成，无再分发许可证（可编辑源图已移至 `assets/source/`）；`public/images/mascots/` 为用户提供的卡通图。公开部署前必须确认授权或替换。
- [ ] **CSP `script-src 'unsafe-inline'`**（`proxy.ts`）：React/Vinext 当前运行方式仍依赖内联脚本，削弱零知识保险库的 XSS 防线。正式部署前应验证框架 nonce/hash 支持并收紧。
- [ ] **生产管理员初始化**：注册账号默认 `permission=0`；上线后必须在可信服务器终端将唯一站主账号提升为 `permission=1`，公开接口不得提供提权能力。可选：`OWNER_TOTP_SECRET` 强制管理员二次验证使用 2FA。
- [ ] **D1 生产绑定**：`wrangler.jsonc` 的 `database_id` 仍为占位符 `00000000-…`；部署前需创建真实 D1、替换绑定并按顺序应用 `drizzle/` 中的全部迁移。

## 中优先（体验 / 正确性）

- [ ] **公开博客与保险库仍共享构建产物/origin**：当前已停用 Giscus 远程脚本并对私人路由使用更严格 CSP；若要恢复第三方评论，必须先把博客和保险库拆到不同 origin。
- [ ] **歌词逐字节奏为线性近似**：句级时间轴均分到字（`components/music-player.tsx`），与真实演唱存在偏差。要逐字精准需增强 LRC 或语音对齐数据源。
- [ ] **第三方公开功能可用性**：一言和网易云搜索/外链播放器依赖外部服务；均有失败降级，但外部接口、版权策略或嵌入规则变更时仍需维护。
- [ ] **音游榜单不是权威防作弊排行**：接口已按谱面限制最大连击并校验明显矛盾值，UI/API 也标注为客户端娱乐榜；若要可信竞技排行，仍需服务端签发单局令牌、上传可验证回放并做服务端重演。
- [ ] **社区信任是审核启发式规则**：新会员累计 3 条已批准评论后可自动发布；当前没有邮箱验证、验证码、设备信誉或完整封禁后台。公网流量增长前应接入受信任的验证码服务并完善封禁/申诉流程。
- [ ] **RSS 主机名 DNS 重绑定边界**：抓取器已阻止私网 IP 字面量、危险协议、凭据、异常跳转/类型和超大正文，但标准 Worker `fetch` 无法在应用层锁定 DNS 解析结果；RSS 地址必须继续仅由站主配置，并依赖部署平台的出站网络隔离。

## 低优先（优化 / 维护）

- [ ] **文章插画无现代格式**：`public/images/night-editorial.png` 单张约 2MB，建议补 AVIF/WebP 变体。
- [ ] **请求限速历史清理**：`request_rate_limits` 每个 scope/client 保留一行并在下次访问时重置，不包含敏感数据；若公网流量明显增长，可增加定时清理过期桶。
- [ ] **文章阅读事件定期清理**：`article_view_events` 每个匿名客户端/文章/UTC 日期保留一行，用于每日去重；计数不会依赖旧事件，可在生产环境增加保留期清理任务控制表体积。
- [ ] **代码风格混杂**：本轮已格式化所有改动文件，少数未触及的旧文件仍为压缩单行风格；可在独立低风险变更中统一格式化并回归。
- [ ] **看板娘台词较少**：`components/kanban-musume.tsx` 的 `LINES` 数组仅 6 句，可按站点人设扩充。
- [ ] **Windows 下 Vite 文件监视偶发漏变更**：组件改动后 dev server 可能持续供应旧模块；重启 dev server 即可，属工具链已知问题。
